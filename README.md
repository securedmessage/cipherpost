# CipherPost Secure Messages — patient page

The official no-install page patients use to exchange end-to-end encrypted messages and
files with care teams using the CipherPost app. © 2026 Roches Motel Software.

- Everything is encrypted and decrypted in the patient's browser.
- Messages travel after the `#` in links, which browsers never send to a server.
- The page's security policy blocks all network requests; it cannot send data anywhere.

Do not edit `index.html` — its security policy pins the exact script, so any change breaks it.
Updates come from Roches Motel Software as a complete replacement.
