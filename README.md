# CipherPost — secure messages (patient page)

The page patients use to exchange end-to-end encrypted messages and files with their care team.
Nothing to install. © 2026 RM Software.

- Messages are encrypted and decrypted only in the patient's browser.
- Encrypted messages travel through an ntfy relay (https://ntfy.sh); the page may contact nothing else.
- Do not edit `index.html` — its security policy pins the exact scripts; any change stops it from running.
